# Solar Odyssey VR

🚀 **[กดเพื่อเล่นเกม](https://rert4kz.github.io/SOLAR/)**

ระบบสุริยะแบบ VR ที่เปิดเล่นผ่านเบราว์เซอร์ได้เลย ยืนอยู่เหนือดวงอาทิตย์แล้วมองดาวเคราะห์ทั้ง 8 ดวงโคจรรอบตัว คลิกดาวเพื่อดูการ์ดข้อมูล แล้วเล่นมินิเกมควิซของดาวดวงนั้นต่อได้

พัฒนาด้วย HTML, JavaScript และ [A-Frame](https://aframe.io/) 1.6.0 ไม่ต้องติดตั้งหรือ build อะไรเพิ่ม

## วิธีเล่น

1. เปิดลิงก์ด้านบน หรือ กดตรง About เพื่อเปิด TAB ใหม่ (ต้องต่ออินเทอร์เน็ต เพราะโหลด A-Frame และฟอนต์จาก CDN)
2. **Desktop:** ใช้เมาส์คลิกที่ดาว
3. **VR (เช่น HTC VIVE):** เปิด SteamVR แล้วเข้าลิงก์ด้วยเบราว์เซอร์ที่รองรับ WebXR (Chrome หรือ Edge) กดปุ่ม VR มุมขวาล่าง แล้วใช้ลำแสงจาก Controller ชี้และกด
4. คลิกดาวเพื่อเปิดการ์ดข้อมูล และกด **เริ่มมินิเกม** เพื่อเล่นควิซ

## รันในเครื่อง

ห้ามเปิด `index.html` ด้วยการดับเบิลคลิก เพราะเบราว์เซอร์จะบล็อกการโหลดภาพ texture (ดาวจะเป็นสีขาว) ให้รันผ่านเซิร์ฟเวอร์ในเครื่องแทน เช่น

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000` หรือใช้ส่วนขยาย Live Server ของ VS Code ก็ได้

## โครงสร้างโปรเจกต์

```
index.html          ฉากหลัก ระบบ VR การ์ด และระบบควิซ
assets/images/      ภาพ texture ของดาว
data/planets/       ข้อมูลและหน้าตาการ์ดของแต่ละดาว
data/quiz/          คำถามควิซของแต่ละดาว
data/quiz-ui/       หน้าตามินิเกมของแต่ละดาว
```

## ดาวในเกม

มีวัตถุท้องฟ้า 9 ดวง ได้แก่ ดวงอาทิตย์, พุธ, ศุกร์, โลก, อังคาร, พฤหัสบดี, เสาร์, ยูเรนัส และเนปจูน

ดาวแต่ละดวงมีไฟล์ของตัวเองครบทั้ง 3 ส่วน (ชื่อไฟล์ตรงกับชื่อดาวเป็นภาษาอังกฤษ เช่น `mars.js`, `saturn.js`)

| ส่วน | ไฟล์ | ทำหน้าที่ |
|---|---|---|
| การ์ดข้อมูล | `data/planets/<ดาว>.js` | ข้อมูลและหน้าตาของการ์ด |
| คำถามควิซ | `data/quiz/<ดาว>.js` | คำถาม ตัวเลือก และเฉลย |
| หน้าตามินิเกม | `data/quiz-ui/<ดาว>.js` | ดีไซน์หน้าจอควิซของดาวดวงนั้น |

เพราะแยกไฟล์ตามดาว สมาชิกในทีมจึงแก้ดาวคนละดวงพร้อมกันได้โดยไม่ชนกัน
